# Hệ thống quản lý vận hành khu đô thị

Đồ án môn Phân tích và thiết kế phần mềm.

## Phạm vi nghiệp vụ

- Quản lý vận hành kỹ thuật
- Vệ sinh môi trường
- An ninh và an toàn
- Dịch vụ khách hàng

## Luồng nghiệp vụ cốt lõi

Phát sinh yêu cầu hoặc lịch định kỳ → tạo phiếu công việc → phân công nhân viên → xử lý → kiểm tra/nghiệm thu → lưu lịch sử và báo cáo.

## Lưu ý cộng tác

Thư mục `documents/` chỉ chứa tài liệu tham khảo và danh sách thành viên, nên được giữ cục bộ và không đưa lên GitHub. Không thêm mật khẩu, token hoặc dữ liệu cá nhân vào repository.
